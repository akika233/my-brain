# Dutch session playbook

How to run one Contact! 2 study block. Planner and chapter pace: [[dutch-b1-planner]]. Log: [[dutch-b1-log]].

## Before the session (2 min)
1. Open tonight’s row in the planner (Mon / Tue / Thu 21:00–23:00)
2. Know the chapter part (e.g. H1A) and which skill block is primary
3. Have tekstboek / werkboek / CD ready (local files — not in git)

## During (protect speaking)
| Night | Block 1 | Block 2 |
|---|---|---|
| Mon | Listening + reading | Speaking (shadow → monologue → record) |
| Tue | Grammar + werkboek | Vocab drill + short speaking |
| Thu | Writing 80–150 words | Listening review + role-play |

Rules:
- Speak every session (even 10 minutes)
- Never skip Mon/Thu listening
- One chapter part fully done before the next

## Correction protocol (writing / speaking)
1. Learner produces Dutch first (no English draft as the main text)
2. Corrector returns: **corrected version** + **top 3 errors** with short Dutch→English gloss
3. Learner rewrites or re-says the same idea once
4. Save a one-line note in [[dutch-b1-log]] (chapter part, minutes, skill)

Prompt pattern for AI: “Corrigeer dit B1-Nederlands en leg 3 fouten uit.”

## After
- Check chapter boxes in [[dutch-b1-log]] when a part is truly done
- Optional: practice site (`dutch-b1-learn.html` — GitHub Pages, Edge, or local PC server) for vocab or chapter test
