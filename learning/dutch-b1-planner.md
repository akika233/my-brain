## Fixed schedule

**Mon · Tue · Thu — 21:00–23:00** (3× 2 hours = **6 h/week**)

No Dutch study required on Wed / Fri / Sat / Sun (optional light review only).

## Weekly mix (what to do each night)

| Night | Block 1 (~21:00–22:00) | Block 2 (~22:00–23:00) |
|---|---|---|
| **Mon** | **Listening + reading** — tekstboek part (A/B/C) + CD tracks; note 10–15 words | **Speaking** — shadow audio, then 10–15 min monologue / role-play; record |
| **Tue** | **Grammar + werkboek** — “Weet u het nog?” + exercises; check answers | **Vocab drill + short speaking** — reuse Monday words in sentences out loud |
| **Thu** | **Writing** — 80–150 words (email / opinion / summary) + correct with Cursor | **Listening review + speaking lab** — re-listen without transcript; role-play chapter functions |

### Skill coverage (every week)

| Skill | When |
|---|---|
| Listening | Mon block 1 · Thu block 2 |
| Reading | Mon block 1 |
| Writing | Thu block 1 |
| Speaking | Mon block 2 · Tue block 2 · Thu block 2 |

### Skill targets every week

- **Listening:** both Monday + Thursday audio blocks
- **Speaking:** all three nights (even 10 min counts)
- **Reading:** finish that week’s tekstboek part(s)
- **Writing:** ≥ 1 text on Thursday (80–150 words)

### Speaking (solo-friendly)

1. **Shadow:** play CD → repeat immediately (pronunciation)
2. **Monologue:** answer chapter “can-do” prompts out loud, record on phone
3. **AI partner:** paste your recording transcript or type answers in Cursor; ask for corrections in Dutch + English
4. **Role-play:** do tekstboek pair exercises by playing both roles

### Writing check

After each writing task, self-check with werkboek oplossingen when available, then ask Cursor: “Corrigeer dit B1-Nederlands en leg 3 fouten uit.”
